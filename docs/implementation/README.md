# Implementation documentation map

Use this directory instead of reading the monolithic legacy plan.

| Need | Read |
| --- | --- |
| Current task and continuation point | `../../SESSION_HANDOFF.md` |
| Priorities and execution order | `../../implementation-plan.md` |
| One Task ID | `task-index.md`, then `tasks/<TASK_ID>.md` |
| Current Production state | `production-status.md` |
| Post-deployment release/hardening sequence | `post-deployment-workflow.md` |
| Controlling technical decisions | `decision-log.md` |
| Important completed history | `history.md` |
| Refactor and consistency checks | `validation.md` |
| Original full plan | `../../implementation_plan_vgu_buddy.md` only when a focused extract is insufficient |

Task files are focused extracts generated from the legacy archive. They retain repeated historical
contracts when a Task ID was updated, so always apply the status and precedence in the lightweight
plan before treating an older excerpt as executable.
