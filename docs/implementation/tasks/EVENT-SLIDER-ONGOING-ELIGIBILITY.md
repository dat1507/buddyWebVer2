# EVENT-SLIDER-ONGOING-ELIGIBILITY — Include ongoing Events in the shared Slider

**Status:** DONE — LOCAL VERIFIED / PRODUCTION NOT RELEASED
**Track:** events
**Assigned:** 2026-11-10
**Depends on:** [Kawazo diagnosis](EVENT-SLIDER-VISIBILITY-001.md)

Allow ongoing scheduled Events on Landing and User Events while preserving publication, cover,
announcement, ordering and limit rules. An Event with a Start Date stops qualifying when its End
Date arrives, or when its Start Date arrives if End Date is missing. An End Date extension can restore
eligibility without a Start Date change. No database migration or Production operation is required.
